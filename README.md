# Miami for the holidays

A painted 3D map of a Dec 23 to Jan 2 trip to Miami and Miami Beach, with live weather drawn on the map.

Live at https://jasterry.github.io/miami-map/

Map data: OpenFreeMap, OpenMapTiles, OpenStreetMap contributors. Forecasts: Open-Meteo (CC BY 4.0). Alerts: National Weather Service. Radar: NWS NEXRAD via Iowa Environmental Mesonet.
